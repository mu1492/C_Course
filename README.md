# Programming with C in Engineering (in Romanian)

Published in 2001, this book is dedicated to C programming for engineering applications. It represented a comprehensive learning resource within the technical constraints and educational environment of its era. The book was developed around Borland C++ 3.1, the IDE used in the faculty's programming laboratories from the Technical University of Cluj-Napoca at the time. The associated computing environment was based on MS-DOS console, with graphics capabilities limited to VGA. Besides algorithms and flowcharts, the book provided extensive coverage of the C language: concepts, techniques, and engineering-oriented applications. Last but not least, it addressed an audience when most computing concepts were not accessible to all high school graduates - in contrast to today's pre-university curricula.

This repository makes the original material available to preserve its historical and educational value, reflecting a particular stage in the development of engineering education and software tools from the late 1990s and early 2000s, and documenting how C programming was taught to students. Therefore, this release is not a ready-to-use or up-to-date programming guide. Readers are encouraged to explore the material in that context, understand the assumptions behind the examples, and consider how programming practices and software technologies have evolved during last decades.

The source files are published in their original form and should not be expected to compile or run with modern development toolchains without modifications. Depending on the example, this may involve replacing compiler-specific extensions, adapting the included headers and legacy library calls, revising graphics code, and addressing differences in language support and runtime behavior.
